# Hi, I'm Dr. Sathish Kumar 👋

Assistant Professor of Computer Science at Amity University Bengaluru, now moving into industry AI roles. My research applies deep learning to biometric and medical image analysis: age and gender determination from offline handwritten signatures and fingerprints, and segmentation and classification of fetal ultrasound images.

- 🎓 PhD in Computer Science (Rani Channamma University, 2024) — biometric data analysis for age and gender determination using digital image processing
- 🔬 Deep learning for image classification: CNNs, transfer learning (VGG16), feature fusion
- 📄 11 peer-reviewed publications — [ORCID: 0000-0001-9374-1980](https://orcid.org/0000-0001-9374-1980)
- 📊 Two public datasets on Mendeley Data:

  - [Age Annotation Offline Handwritten Signature Database (OHSDA)](https://data.mendeley.com/datasets/c5mfhr2xcz/2)
